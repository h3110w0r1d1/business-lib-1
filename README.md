# business-lib-1
Note: there are 2 of the same versions. A typescript(always up to date) and a javascript version. Go to /typescript/ for typescript and /code/ for javascript.


## How to Use
1. download the `/typescript/` folder.
2. You now have the repository to use(in accordence with the license)
### Guide
**main**: examples of how to use(so far). *has been deprecated in version v0.1.0a and beyond*
**business.ts**: the main repository logic
**config.json**: change the values in here to change specific attributes about the library. Refer to the wiki for more information about specific items. **Business.json** is the main logic file for asset bases *only in v0.0.2a*
**utils.ts**: utility functions
**customFunctions.ts**: contains event logic(in v0.1.0a and beyond)

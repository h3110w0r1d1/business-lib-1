# Security Policy

## Supported Versions
All versions are supported, however note that the versions with an :x: are out of date or are in development.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.1a   | :x: |
| 0.0.2a,0.0.b   | :x: |
| 0.1.0a | ✅ |

## Reporting a Vulnerability

Reach out to the repository's owner for critical issues by creating an issue starting with the following: "CRIT-2026-"followed by the version number, a hyphen/em dash and the title of your issue. If determined to be a critical issue you may be credited and/or be reached to gain more information about the vulnerability. *Please do not misuse. If it is **not** a security report, please avoid the use of the prefix*
